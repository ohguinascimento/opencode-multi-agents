# Política obrigatória de criação e alteração

## Regra principal

Este repositório contém apenas o OpenCode e seus agentes. Agentes não devem criar código de produto, novo projeto ou arquivos de aplicação neste diretório.

Antes de criar ou alterar qualquer código de produto:

1. Pergunte ao usuário em qual projeto deseja trabalhar.
2. Se for um projeto novo, pergunte qual pasta deve ser usada.
3. Confirme o caminho absoluto antes de criar arquivos.
4. Verifique se a pasta está vazia, é um repositório Git válido ou foi explicitamente autorizada pelo usuário.
5. Trabalhe somente no caminho confirmado.

Não assuma que o diretório atual é o projeto-alvo. Não crie pastas `app`, `src`, `frontend`, `backend`, `tests` ou equivalentes aqui como parte de um novo projeto.

## Exceções

Pode alterar este repositório somente para manter o OpenCode, seus agentes, comandos, skills, schemas e documentação operacional. Se houver dúvida sobre o escopo, pare e pergunte.

## Resposta obrigatória

Quando não houver projeto confirmado, responda perguntando:

> Em qual projeto deseja trabalhar? Para um projeto novo, qual pasta devo usar?
